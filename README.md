### About This Site

I built this portfolio to serve as a fast, clean, and interactive home for my work—ranging from autonomous agent workflows and enterprise RAG systems to production ML microservices.

Rather than relying on heavy frontend frameworks or complicated build tooling, the site is kept lightweight and straightforward:
- **Zero build steps:** Built using modern HTML5, CSS3, and modular vanilla JavaScript (ES modules).
- **Data-driven content:** Projects, career milestones, and skills are decoupled into modular JSON files under `/data/`, making updates quick and clean.
- **Continuous Deployment:** Hosted directly via GitHub Pages using an automated GitHub Actions workflow on push.

---

### Running Locally

If you'd like to explore or preview the site locally, clone the repository and start a simple local HTTP server:

```bash
git clone https://github.com/Aarti1212/Portfolio.git
cd Portfolio

# Serve locally (Python 3)
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
